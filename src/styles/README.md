# styles/

Global stylesheets. Imported in order by `app/globals.css`.

| File | Purpose |
|------|---------|
| `theme.css` | CSS custom properties (colors, fonts, gradients) |
| `reset.css` | Element resets + base typography |
| `buttons.css` | Shared `.button` primitives |
| `reveal.css` | Scroll-reveal animation classes |
| `keyframes.css` | Shared `@keyframes` animations |
| `responsive.css` | Responsive breakpoints + print styles |
