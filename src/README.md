# src/

Application source code. All paths use the `@/` alias (maps to `./src/`).

| Directory | Purpose |
|-----------|---------|
| `app/` | Next.js App Router — pages, layouts, API routes |
| `components/` | Shared/reusable UI components |
| `features/` | Feature-based modules (portfolio + CmsPanel) |
| `hooks/` | Custom React hooks |
| `lib/` | Utilities, configs, security, validation |
| `services/` | Service layer (API calls, data fetching) |
| `types/` | Shared TypeScript types |
| `data/` | Static/default seed data |
| `styles/` | Global stylesheets |
| `middleware.ts` | Next.js middleware (CSP nonce, redirects) |
